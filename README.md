# Laboratorio LGDR

Página web interactiva de un solo archivo (`index.html`, con HTML, CSS y JavaScript dentro).
Se publica con GitHub Pages desde la rama `main` (carpeta raíz).

🔗 **Ver en línea:** https://amongoooo.github.io/Control/

## Pantalla completa

- Botón ⛶ en la barra superior: toda la app (teoría, simulaciones, prácticas y preguntas) a pantalla completa.
- En iPhone: Compartir → «Agregar a pantalla de inicio» y abrirla desde el ícono (`manifest.webmanifest`).
